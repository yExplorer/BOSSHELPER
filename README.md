# 经营参谋 · AI Business Copilot

一个面向演示的全栈原型：React + Vite 前端、Node.js 内置 HTTP 后端、本地 JSON 模拟数据。前端依赖由 npm 管理；后端不需要额外依赖或 Python。

## 本地运行

1. 安装 Node.js。
2. 安装项目依赖：`npm.cmd install`（PowerShell 环境如果允许 npm 脚本，也可以用 `npm install`）。
3. 启动前后端：`npm.cmd run dev`。
4. 打开 Vite 输出的本地地址（默认 `http://localhost:5173`）。

后端 API 地址：`http://localhost:8000/api/overview`。
